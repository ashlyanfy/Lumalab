# Visual direction used for LumaLab

Сайт собран в едином направлении: светлые облака, цифровые линии, AI/data-сигналы, мягкая природа, стеклянные карточки, спокойный enterprise B2B стиль.

## Главный визуальный prompt

Bright premium B2B technology background, soft white clouds in a clear light blue sky, subtle digital data streams flowing through the clouds, transparent holographic network nodes, gentle sunlight, clean spacious composition, nature-inspired organic shapes, calm futuristic atmosphere, high-end enterprise SaaS style, minimal, elegant, lots of negative space, no people, no text, no logo, no dark cyberpunk, 16:9.

## Icon direction

Premium B2B technology line icons, light blue and graphite palette, soft rounded strokes, minimal glassmorphism style, subtle cloud and nature-inspired details, clean enterprise SaaS aesthetic, transparent background, no text, no logos.
