# LumaLab — Netlify ready package

Готовый статический сайт для загрузки на Netlify.

## Что изменено

1. Светлая визуальная система: облака, цифровые линии, мягкие природные элементы.
2. Логотип в шапке сделан текстовым: `LumaLab / Equity Growth Partner`.
3. Усилен первый экран: LumaLab представлен как growth-партнёр для цифровых активов крупных компаний.
4. Добавлены блоки:
   - безопасный вход и NDA;
   - собственные цифровые продукты LumaLab;
   - критерии отбора компаний;
   - структурированная команда;
   - живые вакансии с задачами и критериями кандидатов.
5. Анкеты расширены:
   - для компании — продукт, метрики, команда, данные, результат за 90 дней, юридическая готовность, equity;
   - для специалиста — роль, стек, AI-инструменты, проекты, результаты, NDA, формат работы.
6. Добавлены тематические SVG-иконки в `assets/icons`.
7. Обновлены PWA manifest, service worker, OG image и страницы `thank-you.html` / `offline.html`.

## Загрузка на Netlify

Загрузите ZIP целиком через Netlify Drop или распакуйте в репозиторий и подключите Netlify. Папка публикации: корень проекта `.`.

## Важно заменить перед публикацией

1. WhatsApp номер в `index.html`: сейчас стоит пример `77000000000`.
2. Email `hello@lumalab.ai`, если нужен другой адрес.
3. `sitemap.xml`, если у сайта будет другой домен.
